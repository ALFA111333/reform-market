# RE:FORM — Circular Design Market

เว็บสาธิต Circular Economy Upcycling Marketplace ภาษาไทย จับคู่เศษวัสดุจากโรงงานกับ Maker เพื่อสร้างสินค้าพรีเมียมและของขวัญองค์กร

**เว็บไซต์ปัจจุบัน:** https://reform-market-thai.saritpong-fifa.chatgpt.site/

> เว็บไซต์บน Sites ปัจจุบันใช้สิทธิ์เข้าถึงของเจ้าของ ลิงก์นี้ไม่ได้เปิดสาธารณะโดยอัตโนมัติ การเก็บซอร์สใน GitHub ไม่ได้เปลี่ยนสิทธิ์ของเว็บ

## ฟีเจอร์

- แค็ตตาล็อก 3 แบบ: Canvas Tote, Zip Pouch และ Shoulder Bag
- เลือกสี ทราย / เขียว / อิฐ และข้อความสูงสุด 24 ตัวอักษร พร้อมภาพแบบที่เลือก
- ปรับจำนวน คำนวณราคา น้ำหนักวัสดุใช้ซ้ำ และแต้ม
- ใส่ตะกร้า แก้ไข/ลบสินค้า กรอกข้อมูล Checkout และใช้ข้อมูลตัวอย่าง
- ยืนยันคำสั่งซื้อทดลอง เก็บประวัติในเบราว์เซอร์ ดาวน์โหลดสรุป และสั่งซ้ำ
- จำลองเริ่มผลิต/รับสินค้า พร้อมรับแต้มครั้งเดียวต่อออร์เดอร์
- Material Passport ตัวอย่าง คำถามที่พบบ่อย และหน้าจอรองรับมือถือ

## เปิดใช้งานในเครื่อง

ไม่ต้องติดตั้งแพ็กเกจหรือ build เปิดโฟลเดอร์นี้ แล้วรัน:

```sh
python3 -m http.server 8000
```

จากนั้นเปิด http://localhost:8000/ ใช้ข้อมูลตัวอย่างใน Checkout เพื่อทดลองทั้งเส้นทาง
Windows ที่ใช้ Python launcher สามารถใช้ `py -m http.server 8000` ได้

## ตรวจระบบ

ต้องมี Node.js:

```sh
node --check app.js
node tests/shop.cjs
```

ชุดตรวจใช้ตัวจำลอง DOM ตรวจการคำนวณ ตะกร้า Checkout การบันทึกออร์เดอร์ การป้องกันแต้มซ้ำ และการสั่งซ้ำ ไม่ใช่การตรวจภาพในเบราว์เซอร์

## โครงสร้างไฟล์

```text
index.html       หน้าเว็บและโครงสร้างหน้าต่าง
style.css        สไตล์และ responsive layout
app.js           ระบบซื้อสินค้าและ localStorage
assets/          ภาพจำลองสินค้าสไตล์สตูดิโอ 3 แบบ
                 และแนวทางภาพ (IMAGE_NOTES.md)
tests/shop.cjs   ชุดตรวจระบบสั่งซื้อ
```

## ขอบเขตเดโม

คำสั่งซื้อเป็นข้อมูลทดลอง ไม่มีการส่งให้ร้าน เรียกเก็บเงินจริง หรือเชื่อม Backend / Google Sheets ข้อมูลเก็บใน localStorage (`reform-shop-v1`) ของเบราว์เซอร์นั้น จึงไม่ซิงก์ข้ามเครื่องและอาจหายเมื่อผู้ใช้ล้างข้อมูลเว็บไซต์

รูปสินค้าเป็นภาพจำลองที่สร้างด้วย AI เพื่อใช้ในโปรเจกต์ ไม่ใช่ภาพถ่ายสินค้าที่ผลิตและจำหน่ายจริง ภาพถ่ายตัวอย่างใช้สื่อรูปทรง ส่วนภาพแบบที่เลือกแสดงสีและข้อความที่ผู้ใช้ตั้งค่า

CRM แยกเป็น Google Sheets 3 แท็บ: Contact, Pipeline / Transaction และ CRM Interaction & Points Log การเชื่อมข้อมูลและ Make Automation เป็นแผนระยะถัดไป ไม่ได้ตั้งค่าใน repo นี้

## การนำไปโฮสต์

ไฟล์ชุดนี้เป็น static HTML/CSS/JavaScript สามารถใช้บนผู้ให้บริการ static hosting ได้โดยไม่ต้อง build ใช้ `index.html` ที่ root การจัดเก็บซอร์สใน GitHub ไม่ได้เปิด GitHub Pages หรือเผยแพร่เว็บเพิ่มโดยอัตโนมัติ

ภาพสินค้าและซอร์สครบใน repo ไม่พึ่ง URL ภาพภายนอก และไม่รวม credentials หรือข้อมูลออร์เดอร์ของผู้ใช้
